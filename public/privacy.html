* AniKotoAPI

Privacy Policy

Last updated: 2026-10-30

1. Overview

AniKotoAPI ("the Service") is a free, open-source REST API that provides anime data by scraping publicly available information from anikototv.to and related domains. This Privacy Policy explains how we handle data when you use the Service.

2. Data We Collect

The website stores account information when you register and records first-party visitor statistics when you browse public content pages.

  • Accounts: email, display name, a password hash and session records. Login uses an HttpOnly session cookie.
  • Visitor statistics: IP address, approximate country/region/city, public page path, page views and activity timestamps. Query strings, passwords, admin tokens and account identities are not included in these statistics.
  • Visitor estimates: a server-side keyed hash of IP address and browser user agent groups activity without a tracking cookie. People sharing the same network and browser may be counted together; changing networks may count separately.
  • Online status: visible pages send a heartbeat every 30 seconds. A visitor is considered online for 90 seconds after the last recorded activity.

3. Third-Party Data Sources

The Service scrapes data from anikototv.to and related domains. This data (anime titles, descriptions, images, episode information) belongs to the respective content owners. We do not claim ownership of this data.

If you are a content owner and wish to have your data removed from this API, please open an issue on our GitHub repository.

4. Data Storage

Accounts and statistics are stored in the site's SQLite database. Detailed visitor IP/location/activity records are removed after 30 days without activity, during the next statistics request. Anonymous daily and lifetime counters are retained. Statistics begin when this feature is enabled, without importing historical traffic.

  • Only authenticated administrators can access detailed visitor records.
  • Page paths are recorded without search queries or URL fragments.
  • Server/CDN access logs and operator backups may have separate retention settings.

5. Data Sharing

When IP geolocation is enabled, the server sends public visitor IP addresses to ipwho.is over HTTPS to estimate city, region and country. Results are cached; precise GPS location is not collected. The operator can disable these lookups with VISITOR_GEO_LOOKUP=false while retaining local counters. The hosting/CDN and embedded video providers also process requests under their own policies. We do not sell visitor records.

6. Children's Privacy

The Service is not directed at children under 13. We do not knowingly collect information from children under 13.

7. Changes to This Policy

We may update this Privacy Policy from time to time. Changes will be posted on this page with an updated "Last updated" date.

8. Contact

For questions about this Privacy Policy, open an issue at github.com/Shineii86/AniKotoAPI/issues.
